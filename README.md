# SheetDiff 📊

**自动发现两个 Excel 表之间的过滤规则。**

SheetDiff 是一个 Go 语言 CLI 工具，用于比对同一个 Excel 文件中的两个 Sheet（表），通过主键匹配后，运用**基于集合论的规律发现算法**，自动找出哪些字段条件能解释"为什么某些行只存在于一个表中而不在另一个表中"。

## 工作原理

给定同一个 Excel 文件中的两个 Sheet（如 "主表" 和 "参考表"），SheetDiff 执行以下流程：

1. **读取配置** — 从专用的"配置"Sheet 读取字段映射、主键定义、Sheet 名称等
2. **主键匹配** — 根据复合主键做行匹配，产生三个集合：**匹配行**、**主表独有行**、**参考表独有行**
3. **逐字段分析** — 对每个非主键字段，自动发现能覆盖**全部**匹配行的过滤模式，同时最小化对独有行的误伤
4. **构建支配关系森林** — 将发现到的规律组织成层次结构，最优规律支配次优规律
5. **推荐最优组合** — 自动找出能解释数据差异的最佳过滤条件组合

## 核心概念：什么是"独有"？

这是理解 SheetDiff 输出结果最关键的概念。

### 直观理解

假设你有两个名单：

- **主表**（最新版）：包含 100 个员工，其中 80 人也出现在参考表，另 **20 人只在主表有**
- **参考表**（旧版）：包含 90 个员工，其中 80 人也出现在主表，另 **10 人只在参考表有**

我们说：
- **主表独有行** = 那 20 个"在主表有、参考表没有"的人
- **参考表独有行** = 那 10 个"在参考表有、主表没有"的人

### 用集合论理解

```
主表主键值集合  = {1, 2, 3, ..., 100}                    ← 100行
参考表主键值集合 = {1, 2, ..., 80, 101, 102, ..., 110}   ← 90行
                          ↑前80个与主表重叠  ↑后10个是独有的

匹配行（主键值在两边都存在）= {1, 2, ..., 80}             ← 80行
主表独有行（主键值仅在主表）= {81, 82, ..., 100}          ← 20行
参考表独有行（主键值仅在参考表）= {101, 102, ..., 110}    ← 10行
```

### 为什么"独有"很重要？

因为"独有行"就是你要找的**差异**。SheetDiff 的核心目标就是：**自动找出规律，解释为什么这些行会"独有"**。

比如发现：
- 所有主表独有行都是 `部门 = 技术部` 的行 → 说明主表比参考表多了技术部的人
- 所有参考表独有行都是 `状态 = 已离职` 的行 → 说明参考表还包含了已离职人员

### D 集合（误伤独有行数）

这是算法中最重要的衡量指标。假如：

- 某字段规律 `部门 = 技术部` **覆盖了全部 80 个匹配行**
- 但在 **20 个主表独有行**中，有 **3 个不是技术部的**
- 那么 D = 3，误伤率 = 3/20 = 15%

**D = 0** 表示完美规律，不会误伤任何独有行，这就是算法要找的最优解。

> **一句话总结**：独有 = 两个表匹配不上的行。"独有行"就是差异本身，而 D 值度量的是一个规律在解释差异时"误伤"了多少本不该被包含的行。

## 功能特性

- **5 种规律类型**（每字段自动检测）：
  - `等于` — `部门 = 技术部`
  - `枚举` — `部门 ∈ {技术部, 市场部}`
  - `前缀匹配` — `编码 = A*`
  - `前缀枚举` — `编码 ∈ {A*, B*}`
  - `数值范围` — `年龄 >= 32`
- **复合主键**支持（多个字段联合作为主键）
- **支配关系森林**可视化 — 直观展示条件之间的优劣关系
- **最优组合推荐** — 自动发现误伤为零的最佳过滤条件组合
- **直接输出到 Excel** — 在原文件中生成"分析结果"Sheet，带颜色高亮
- **重复列名检测** — 发现重复列名时快速失败，避免歧义
- **零外部依赖** — 直接操作 `.xlsx` 文件，无需数据库

## 使用方法

```
SheetDiff.exe <文件.xlsx>
```

或者直接将 `.xlsx` 文件拖拽到程序图标上。如果不指定文件，程序会自动查找当前目录中的 `.xlsx` 文件。

### Excel 配置

你的 Excel 文件中需要包含一个名为 **"配置"** 的 Sheet，结构如下：

| 键 | 值 |
|-----|-------|
| 主表 | 主表Sheet名称 |
| 参考表 | 参考表Sheet名称 |
| 主表表头行 | 1 |
| 参考表表头行 | 1 |

*（空行 — 分区标记，分隔基础配置和字段映射）*

| 主表字段 | 参考表字段 | 是否主键 |
|----------|-----------|---------|
| id | id | 是 |
| name | name | |
| department | dept | |

默认值：主表 Sheet 名 = `"主表"`，参考表 Sheet 名 = `"参考表"`，表头行号 = 1。

## 输出说明

SheetDiff 会在你的 Excel 文件中新增一个 **"分析结果"** Sheet，包含以下内容：

1. **统计概览** — 行数、匹配率
2. **推荐过滤条件组合** — 能完全解释独有行的最佳条件组合
3. **支配关系森林** — 条件之间关系的树形展示（绿色 = 完美，误伤为零）
4. **过滤条件链详情** — 每个字段发现的所有规律及其误伤指标
5. **数据样本** — 匹配行、主表独有行、参考表独有行的示例数据
6. **主键高亮** — 源 Sheet 中匹配成功的主键单元格标记为绿色背景

## 算法原理

核心是基于集合论的：

- 对每个非主键字段，生成候选模式（等于、枚举、前缀、范围）
- 每个模式定义一个 **D 集合** — 即该规律会错误纳入的独有行集合（误伤）
- 构建**支配关系森林**：若模式 A 的 D 集合 ⊆ 模式 B 的 D 集合，则 A 支配 B
- 搜索 **D 集合互不相交**的模式组合，实现总误伤为零的最优解

详见 [ALGORITHM_DESIGN.md](ALGORITHM_DESIGN.md)（算法设计文档，中文）。
